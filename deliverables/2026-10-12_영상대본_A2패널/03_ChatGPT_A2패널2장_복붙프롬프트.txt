너는 미술관 전시 그래픽, 한국어 편집 디자인, 인터랙션 디자인을 함께 이해하는 아트디렉터다. 첨부된 실제 웹사이트 캡처와 아래 확정 원고를 사용해 졸업 전시용 A2 세로 패널 정확히 두 장을 하나의 디자인 시스템으로 제작해 줘. 설명이나 아이디어 제안에 그치지 말고, 네 환경에서 가능한 최선의 완성된 편집 결과물과 파일을 만들어 줘.

1. 작품과 전달 목적
작품명: 나를 만든 세 가지 미술사조
영문 브랜드: THREE ART MOVEMENTS THAT SHAPED ME
브랜드 중심어: 질서 · 상상 · 감정
매체: 인터랙티브 웹사이트 / 화면 녹화와 내레이션 영상
영상 길이: 약 4분 45초, 최종 4~5분
영상에는 별도의 긴 설명 자막을 추가하지 않는다. 패널이 작품 정보, 개념, 나에게 준 영향, 구현 방식의 구체적인 설명을 담당한다.
관객은 미술사를 깊이 공부하지 않은 일반 전시 관람객이다. 2m 거리에서 제목과 구조, 1m에서 요점, 50~80cm에서 세부 설명이 읽혀야 한다.
패널 1은 WHAT / WHY: 작품·사조·나에게 준 영향.
패널 2는 HOW / EXPERIENCE: 행동→화면 변화→개념→디자인 의도.
세 사조를 두 장에 불균등하게 나누지 말고, 양쪽 모두 A 르네상스 / B 초현실주의 / C 낭만주의의 같은 순서와 높이에 배치해 서로 대조할 수 있게 해 줘. 이 순서는 사이트 탐색 순서이며 역사적 연대순이나 작가 개인의 실제 학습 연대기로 주장하지 않는다.

2. 나의 목소리 — 해석의 기준
르네상스: 감각에만 기대던 시각적·디자인적 판단에 질서를 부여했고, 선·비례·배치의 관계로 더 선명하게 판단하게 했다. 이 영향은 내가 직접 제공한 내용이다.
초현실주의: 창의력에 도움을 주었다. 이를 ‘익숙한 요소의 관계를 바꾸고 예상 밖의 조합을 받아들이는 태도’로 구체화했다.
낭만주의: 이번 작업의 제안된 작가적 해석은 ‘명확한 구성에 감정이 머물 자리를 만드는 태도’다. 특정한 개인 경험이나 과거 사건을 지어내지 말 것.
아래 패널 원고의 1인칭을 유지하되, 디자인 지침이나 제작 메모는 인쇄 화면에 넣지 말 것.

3. 반드시 이어받을 사이트 브랜딩
참고 캡처 01_hub.png를 먼저 자세히 관찰해라. 이 파일이 브랜딩의 1차 기준이다.
크림색 종이 같은 바탕, 짙은 검정, 굵고 압축된 영문 산세리프 제목, 사조명의 고전적인 세리프, 작품 옆에 붙는 미술관식 라벨, 직각 프레임과 얇은 구획선, 넓은 여백을 계승한다.
영문 브랜드의 존재감을 살리되 한국어 제목과 본문을 주인공으로 한다. 웹 화면의 가로형 구성을 인쇄물의 세로형 그리드로 재편집한다.
팔레트 제안: 공통 바탕 #F3EFE4 전후의 따뜻한 아이보리, 본문 #171715. A의 색 #C8A86B / #3A2510, B의 색 #0D1220 / #A8CBE4, C의 색 #6B7F99 / #07101C. 사이트와 맞추며 실제 인쇄에서 확인할 색이지 검증된 CMYK 값이라는 뜻은 아니다.
전체 면적 대부분은 밝은 바탕과 진한 활자로 유지하고, 사조별 색은 분류 라벨·가느다란 선·키워드·작은 도형에 한정한다. 캡처 자체의 어두운 화면이 충분한 대비를 만든다.
그래픽 모티프는 A: 한 점으로 수렴하는 선, B: 어긋난 직사각형/셋으로 분할된 몸, C: 낮은 밀도의 안개층/수평선. 개념을 설명하는 자리에서만 아주 절제해 사용한다.
굵은 검정 제목과 명조체 소제목의 대비, 정확한 정렬, 이미지의 크기 차이, 여백으로 완성도를 만든다. 불필요한 3D 모형·휴대폰/노트북 목업·스톡 이미지·AI로 다시 그린 명화·과한 그림자·둥근 대시보드 카드·네온 효과는 넣지 않는다.

4. 인쇄 규격과 타이포그래피
완성 재단 크기: 각 420 × 594 mm, 세로형 A2. 두 장은 별개의 페이지/파일이다. 한 장의 긴 포스터나 합성 목업으로 대신하지 말 것.
기본 외곽 여백 20mm. 중요 요소는 재단선 안쪽 최소 15mm, 실제 편집은 20mm 안쪽.
6열 그리드: 유효 폭 380mm, 열 간격 6mm, 열 폭 약 58.33mm. 패널 두 장의 A/B/C 행 시작점을 가능한 한 맞춘다. 4mm 또는 5mm 기준선 간격으로 정돈하되 기계적으로 모든 글줄에 강제하지는 않는다.
타이틀 42~54pt, 사조/행 제목 25~30pt, 핵심 문장 20~23pt, 본문 17~19pt, 캡션 12~14pt, 출처 10~11pt를 시작점으로 실제 렌더를 보고 조정한다. 필수 본문을 16pt 미만으로 줄여 억지로 수용하지 않는다. 제목은 멀리서, 본문은 가까이서 읽는다는 역할을 구분한다.
한글 제목은 Noto Serif KR 또는 Nanum Myeongjo 계열, 본문은 Noto Sans KR/Pretendard 계열, 영문 브랜드는 굵은 산세리프. 실제 설치·임베딩 가능한 글꼴만 사용하고 대체 글꼴 적용 시 기록한다. 얇은 명조체를 긴 본문에 쓰지 않는다.
한글 본문은 좌측 정렬, 행간 145~155%, 단어 단위 줄바꿈, 과도한 자간 금지. 짧은 두 줄 고아문장, 제목 한 글자 줄바꿈, 출처와 캡션 중첩을 없앤다.
평면 인쇄 파일이 우선이다. 배경이 재단선까지 닿는다면 3mm 도련을 별도로 포함해 파일 크기 426 × 600mm로 준비하고 TrimBox는 420 × 594mm로 설정한다. 도련 없는 미리보기에는 이를 섞지 않는다.
300ppi 기준 재단 크기 PNG는 약 4961 × 7016px이다. 래스터 파일에 DPI 숫자만 붙이는 것과 실제 픽셀 해상도를 구분한다. 텍스트는 가능한 한 벡터·편집 가능한 레이어로 유지한다.
사진은 배치 크기에 따른 유효 해상도를 계산해 적어도 200ppi, 가능하면 300ppi 이상 확보한다. 제공된 캡처는 3840 × 2160px이므로 187 × 105mm 안팎으로 쓸 때 충분하다. 이미지를 늘려 인위적으로 ‘고해상도’라고 주장하지 않는다.
인쇄소 ICC 프로파일이 없으므로 임의의 CMYK 값을 보장하지 않는다. RGB 검토용 파일과 인쇄소 변환용 원본을 구분하고, 지원되는 경우에만 도련·글꼴 임베딩·출력 프로파일이 검증된 인쇄 PDF를 함께 제공한다.

5. 두 장의 레이아웃
배치는 아래 시작안을 기준으로 실제 원고와 이미지의 무게를 보며 미세 조정하되, 세 행을 대응시키는 구조를 유지해라.
공통: x=20~400mm, y=20~574mm의 편집 영역. 상단 y=20~136mm, A행 y=148~272mm, B행 y=284~408mm, C행 y=420~544mm, 푸터 y=554~574mm. 행 사이 12mm를 확보한다. 넘침이 생기면 행 높이를 두 장 함께 조정한다.

패널 1 — 나를 만든 시선
상단은 국문 프로젝트명 + 영문 브랜드 + 질서/상상/감정 + 짧은 프로젝트 소개. 01_hub.png를 약 118~130mm 너비의 작고 선명한 브랜드 프리뷰로 배치하되 제목보다 강해지지 않게 한다. 이미지를 줄여 내용을 못 읽게 되면 해당 프리뷰는 색과 구성의 맥락용이며 본문은 별도 활자로 제공한다.
아래 A/B/C 각 행은 왼쪽 약 122mm 이미지 열, 오른쪽 약 246mm 설명 열, 사이 12mm. 이미지에는 원본 화면 전체 또는 작품 중심 크롭을 사용하고 아래에 작품명과 ‘실제 사이트 화면’ 캡션을 붙인다. 본문은 ‘작품과 개념’ + ‘나에게 남은 것’의 두 작은 문단으로 정리한다. 핵심 영향 한 문장을 볼드로 강조한다.
패널 1 주 이미지: A=02_renaissance_artwork.png, B=12_surrealism_artwork.png, C=08_romanticism_artwork.png. 각 이미지가 들어간 원본 화면의 형태·색·텍스트는 위조하지 않는다.
푸터: 패널 번호 01/02, 핵심 결론, 최소한의 출처 키. 작가 이름과 학교 등 미제공 정보는 추측하거나 [이름] 같은 플레이스홀더를 인쇄하지 말고 아예 제외한다.

패널 2 — 시선을 움직이는 방법
상단은 ‘그림의 개념을, 관객의 행동으로.’ + 영문 부제 + 도입 + ‘작품 감상→개념 탐구→직접 조작→작품 다시 보기’의 간결한 흐름도.
각 A/B/C 행의 제목 아래, 왼쪽 216mm에 BEFORE/AFTER 화면을 각각 105×59.1mm로 나란히 놓고 사이에 6mm 간격을 둔다. 오른쪽에는 12mm 간격을 두고 152mm 폭의 설명 열을 둔다. 왼쪽 이미지 아래에 전후 캡션과 ‘입력→반응→개념’을 놓는다. 각 행은 124mm 높이 안에서 제목 약 16mm, 본문·이미지 약 96mm와 하단 여백을 사용한다. 17pt 본문이 넘치면 B의 보조 설명을 먼저 덜어내고, 그래도 넘치면 두 패널의 행 높이를 함께 조정한다. 본문을 작게 줄여 억지로 넣지 않는다.
A=05_renaissance_scattered.png + 06_renaissance_composed.png
B=17_surrealism_chance_before.png + 18_surrealism_chance_after.png
C=10_romanticism_calm.png + 11_romanticism_storm.png
두 상태의 차이가 보이는 동일 위치·동일 비율 크롭을 택한다. 이미지 간 화살표와 A/B/C 대응 라벨은 별도 벡터로 만든다. 캡처에 존재하지 않는 컨트롤이나 효과를 덧그리지 않는다.
‘조작 / 변화 / 의미’는 짧은 라벨로 명확히 구분한다. ‘입력→반응→개념’은 굵은 한 줄 또는 세 칸짜리 가는 도식으로 보여 준다. B의 보조 설명은 공간이 부족할 때 줄일 수 있지만, 두 캡처의 이름·핵심 조작·개인적 영향은 삭제하지 않는다.
푸터: 02/02, 맺음 문장, 출처 키. 마지막 문장은 패널 전체의 가장 큰 글자가 아니라 읽기를 마무리하는 명확한 서명처럼 다룬다.

6. 캡처 사용과 사실 정확성
첨부 파일만 실제 사이트 화면으로 취급한다. 원본 캡처를 배치·크롭할 수는 있지만 생성 모델로 UI나 그림을 다시 그리지 않는다. 캡처에 이미 들어 있는 작은 글자는 설명의 유일한 수단이 될 수 없으므로 핵심 내용은 별도 텍스트로 조판한다.
일부 캡처가 첨부되지 않았다면 그 파일을 실제로 본 것처럼 꾸미지 말고, 누락 파일명을 한 번에 알려 주고 해당 이미지 위치를 비워 둔 검토본을 만든다. 현재 대화의 로컬 경로를 스스로 열 수 있다고 가정하지 않는다.
패널에 사용한 이미지는 모두 ‘실제 사이트 화면’이라는 성격을 유지한다. 작품 도판만 크롭하면 ‘사이트 인트로의 작품 이미지 부분’이라고 적는다.
원근법은 ‘모든 선이 하나로 모인다’가 아니라 ‘깊이 방향의 평행선이 소실점으로 수렴한다’로 설명한다. 원근법이 다른 그림을 열등하거나 잘못된 그림으로 규정하지 않는다.
마그리트의 《빛의 제국》은 여러 판본이 있다. 사이트의 1956 표기를 해당 이미지의 검증된 원작 연도로 확대 재사용하지 않는다. 패널은 위 원고처럼 연작·모티프로 표기하고 판본별 연도는 생략한다.
《안개 바다 위의 방랑자》는 사이트에 1818로 표시되지만 현재 함부르크 미술관은 약 1817로 기재한다. 패널의 별도 캡션에는 연도를 쓰지 않고 작가·작품명만 둔다. 실제 캡처의 문자를 멋대로 덮어쓰지 않는다.
브랜딩과 본문에 쓰는 A/B/C는 새로 정한 편집용 식별자다. 사이트 내부의 01/02/05 숫자를 학습 연대기나 역사적 순서로 설명하지 않는다.
르네상스는 종교가 사라진 시대가 아니며, 낭만주의는 사랑 이야기만을 뜻하지 않는다. 숭고를 공포와 경외의 단순한 합으로만 정의하지 않는다.
본 프로젝트의 이미지 조각 놀이를 다수가 종이를 접어 그리는 역사적 우아한 시체와 동일하다고 쓰지 말고, ‘우연성을 디지털 재조합으로 재해석’했다고 쓴다.
갤러리의 모든 작품을 작은 썸네일로 늘어놓거나 불확실한 연도를 추가하지 않는다. 세 가지 핵심 작품과 세 가지 핵심 조작을 깊이 있게 보여 주는 것이 우선이다.
HAND 카메라 기능은 이번 패널의 핵심 약속에 포함하지 않는다. 실제 검증하지 않은 손 인식 성능, 사용자 조사, 수상, 성과 수치를 만들어내지 않는다.

7. 반드시 사용할 패널 원고
아래 원고의 [대괄호]는 편집 지시용 구획이며 그대로 인쇄하지 않아도 된다. 실제 본문과 캡션은 바꾸지 말고 조판한다. 꼭 필요한 축약은 중복 접속어와 B의 보조 설명에 한해 최소한으로 하고, 최종 응답에 바꾼 문장을 기록한다. 본문 전체를 두세 개의 슬로건으로 대체하지 말 것.

[프로젝트 소개]
미술사조는 내가 이미지를 바라보고 디자인을 판단하는 방식이 되었다. 르네상스에서는 감각을 정리할 기준을, 초현실주의에서는 익숙한 관계를 바꾸는 창의력을, 낭만주의에서는 화면에 감정을 담는 시선을 발견했다. 이 작업은 그림 속 개념을 직접 움직일 수 있는 웹 인터랙션으로 옮긴다. 관객은 작품을 보고, 원리를 바꾸고, 다시 작품을 바라본다.

[A / 르네상스 / 감각에 질서를 세우다]
RENAISSANCE · 주로 14–16세기
라파엘로 산치오, 《아테네 학당》, 1509–1511

작품과 개념
고대의 지식과 인간의 탐구를 새롭게 바라본 르네상스. 《아테네 학당》에서는 철학자들이 건축 공간 안에 질서 있게 배치된다. 깊이 방향의 평행선이 소실점으로 수렴하는 선원근법은 평면에 깊이를 만들고 시선을 조직한다. [1]

나에게 남은 것
감각에 주로 의존하던 나의 시각적 판단에 기준이 생겼다. 선과 비례, 배치의 관계를 살피며 왜 명확하게 보이는지 설명하고 판단하게 되었다.

사진 캡션: 실제 사이트 화면 — 그림에서 공간의 구조를 읽는 시작점.
연결 라벨: A → 기준점을 놓고 관계를 구성하기

[B / 초현실주의 / 익숙한 관계를 다시 연결하다]
SURREALISM · 1924년 선언을 중심으로 전개
르네 마그리트, 《빛의 제국》 연작을 모티프로 한 사이트 화면

작품과 개념
꿈과 무의식, 우연을 탐구한 초현실주의. 《빛의 제국》은 밝은 하늘과 어두운 거리를 한 화면에 둔다. 익숙한 대상의 시간·크기·맥락을 어긋나게 하는 데페이즈망은 평범한 장면을 낯설게 보게 한다. [2, 3]

나에게 남은 것
창의력은 없는 것을 만들어 내는 데서만 나오지 않는다. 익숙한 요소의 관계를 바꾸고 예상하지 못한 조합을 받아들이는 태도가 내 발상의 범위를 넓혔다.

사진 캡션: 실제 사이트 화면 — 낮의 하늘과 밤의 거리가 공존하는 장면.
연결 라벨: B → 크기와 시간, 이미지 조각의 관계 바꾸기

[C / 낭만주의 / 화면에 감정이 머물게 하다]
ROMANTICISM · 18세기 후반–19세기 전반을 중심으로 전개
카스파르 다비드 프리드리히, 《안개 바다 위의 방랑자》

작품과 개념
개인의 감정과 상상력, 자연의 힘에 주목한 낭만주의. 방랑자의 뒷모습은 관객을 같은 방향의 응시로 이끈다. 안개는 시야를 가리며 상상을 열고, 인간을 압도하는 자연은 경외와 두려움이 얽힌 숭고의 경험을 환기한다. [4, 5]

나에게 남은 것
명확하게 구성하는 것에 더해, 화면이 어떤 감정을 남기는지 묻게 되었다. 빛과 여백, 드러남과 가려짐을 조절하며 감정이 머무는 디자인을 지향한다.

사진 캡션: 실제 사이트 화면 — 풍경을 바라보는 한 사람의 시선.
연결 라벨: C → 빛과 안개, 비바람으로 분위기 조절하기

패널 2 / 02 — 시선을 움직이는 방법

[제목]
그림의 개념을, 관객의 행동으로.
FROM ART TO INTERACTION

[도입]
버튼을 누르는 일 자체가 목적은 아니다. 손의 작은 움직임이 화면의 관계를 바꾸고, 그 변화가 미술사조의 개념과 나의 디자인 태도를 드러내도록 구성했다.

[공통 경험 흐름]
작품 감상 → 개념 탐구 → 직접 조작 → 작품 다시 보기

[A / 기준점을 놓다]
르네상스 · 감각에서 구성으로

조작
화면을 탭해 소실점을 놓고, 다른 위치로 옮긴다.
변화
흩어진 인물과 건축의 선이 기준점에 따라 재배치된다.
의미
하나의 기준이 전체의 관계를 바꾼다. 감각적 인상을 선·비례·배치의 판단으로 연결하는 나의 변화를 표현했다. 이것은 원근 구성의 원리를 체험하도록 만든 재해석이다.

전후 캡션: 배치 전 — 흩어진 요소 / 배치 후 — 기준점에 따라 구성된 공간
입력 → 반응 → 개념: 탭 → 소실점과 배치 변화 → 질서와 판단

[B / 우연을 받아들이다]
초현실주의 · 익숙함에서 새로운 관계로

조작
레버를 당겨 머리·몸통·다리를 무작위로 조합한다. 각 부분을 눌러 따로 바꿀 수도 있다.
변화
같은 이미지 조각이 전혀 다른 존재와 이야기로 연결된다.
의미
서로의 그림을 가리고 이어 그린 ‘우아한 시체’의 우연성을 디지털 재조합으로 옮겼다. 예측하지 못한 결과를 다음 발상의 출발점으로 삼는 태도를 표현했다. [6]

전후 캡션: 조합 A — 처음 만난 세 조각 / 조합 B — 레버가 만든 새로운 만남
입력 → 반응 → 개념: 당기기 → 무작위 조합 → 우연과 창의력
보조 설명: 개념 화면에서는 사과의 크기를 바꾸고, 꿈의 방에서는 줄을 당겨 장면을 전환한다. 서로 다른 체험이 익숙한 관계를 낯설게 만든다는 하나의 생각으로 이어진다.

[C / 분위기를 움직이다]
낭만주의 · 풍경에서 감정으로

조작
화면을 클릭해 새벽에서 폭풍으로 전환한다. 누른 채 움직여 비바람의 방향에 관여하고, 슬라이더로 날씨를 조절한다.
변화
같은 풍경의 빛과 안개, 강수와 움직임이 달라진다.
의미
구도가 남아 있어도 분위기는 달라질 수 있다. 감정을 설명하는 문장 대신, 관객이 일으킨 날씨의 변화가 평온과 긴장, 경외의 차이를 느끼게 한다.

전후 캡션: 고요한 새벽 — 멈춰 바라보기 / 폭풍 — 흔들리는 풍경 마주하기
입력 → 반응 → 개념: 클릭·드래그 → 날씨와 방향 변화 → 감정과 숭고

9. 제작 방식과 결과물
가능하면 실제 편집·코드·레이아웃 도구로 제작하고 한글을 텍스트로 조판해 줘. 긴 한글 전체를 이미지 생성기에 그리게 한 결과를 최종 인쇄본이라고 부르지 않는다. 이미지 생성만 가능한 환경이면 정확한 원본 캡처가 들어간 편집본을 만들 수 있는지 먼저 구분하고, 스타일 시안 2장과 별도 정확한 문안·좌표 명세까지 만들어 그 한계를 밝힌다.
원하는 결과물:
① panel_01.png와 panel_02.png: 두 패널을 각각 정면에서 본 평면 미리보기
② 두 장을 나란히 비교하는 검토용 미리보기 1장 — 이것은 개별 파일을 대체하지 않는다.
③ 가능한 편집 원본 2페이지 또는 2개 파일: Figma/Illustrator/SVG/HTML 등 실제 생성 가능한 형식. 생성하지 못한 포맷의 파일이 있다고 주장하지 않는다.
④ 지원되는 경우 A2 인쇄 PDF 2페이지, 글꼴 포함 또는 윤곽 처리, 도련/재단 영역 명확히 구분. 미검증이면 ‘검토용’이라고 표시하고 인쇄 준비가 완료됐다고 말하지 않는다.
⑤ 텍스트 원고와 이미지 파일명 대응표, 출처, 실제 출력 규격을 적은 간단한 제작 메모.
누락된 이름·학교·QR·링크 때문에 멈추지 말고 그 요소를 제외하고 완성한다. 가짜 QR코드를 만들지 않는다.

10. 완료 전에 스스로 확인할 것
두 장이 한 작품처럼 보이는가? 세 사조가 A/B/C 같은 위치·색·번호로 연결되는가? 사이트의 굵은 영문/명조 사조명/아이보리/직각 프레임이라는 특징이 남아 있는가?
패널 1은 작품과 영향, 패널 2는 조작과 의미를 충분히 설명하는가? 각각 독립적으로 읽어도 이해되는가?
실제 캡처가 선명하고 왜곡 없이 들어가 있는가? 전후 상태 차이가 분명한가? 이미지 위에 긴 글을 겹치지 않았는가?
한글 오탈자, 깨진 글리프, 잘린 문장, 글상자 넘침, 작은 본문, 출처 누락이 없는가? 모든 본문을 실제 렌더에서 확대 확인했는가?
PDF를 만든 경우 페이지 크기·글꼴·도련을 실제로 검사했는가? ‘300dpi’라는 말만 적지 않고 픽셀과 유효 해상도를 확인했는가?
완료되면 디자인 의도를 5문장 이내로 설명하고, 실제 만들어진 파일을 제공해 줘.
