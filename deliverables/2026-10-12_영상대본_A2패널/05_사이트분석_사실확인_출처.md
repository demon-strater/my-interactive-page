# 사이트 분석과 사실 확인

작성 기준: 2026-10-12. 작업 시작 시점의 로컬 파일을 읽고 핵심 화면을 렌더링해 검토했다. 분석 대상은 사용자가 이야기한 르네상스·초현실주의·낭만주의 세 사조다. 사이트 소스는 수정하지 않았다. 작업 종료 무렵 인상주의를 추가하는 별도 변경이 나타났으나, 이번 대본·패널은 세 사조 범위를 유지한다. 제공 캡처와 원고는 그 범위의 기준 자료다.

## 작업의 중심

이 사이트의 강점은 작품을 보여준 뒤 그 안의 시각 원리를 변형 가능한 모델로 바꾸고, 다시 갤러리로 돌아온다는 점이다. 대본은 ‘사조 설명 → 조작 안내’의 나열 대신 ‘작품에서 발견한 것 → 나에게 준 영향 → 관객이 일으키는 변화’로 묶었다. 패널은 같은 A/B/C 항목을 두 장에서 대응시켜 의미와 구현을 연결한다.

사용자가 직접 밝힌 영향은 르네상스의 질서와 판단 기준, 초현실주의의 창의력이다. 낭만주의의 ‘구성 안에 감정이 머물 자리’는 사용자의 요청에 따라 제안한 해석이다. 실제 개인 경험·학습 순서·과거 사건을 추가로 만들어 넣지 않았다.

## 화면에서 읽힌 브랜드

메인: 아이보리 바탕, 굵은 검정 대문자 브랜드, 세리프 사조명, 직각 프레임과 그림 옆 라벨. 내부: 어두운 캔버스, 명조 제목, 작품 중심의 감상 장면, 사조별 분위기. 따라서 패널은 밝은 편집 그리드를 공통 기반으로 삼고 실제 어두운 화면을 이미지로 보여주는 편이 일관된다. 세 사조를 각각 다른 포스터처럼 만들지 않는다.

## 잘못 확장하지 않은 내용

1. 메인은 사용자 휠·드래그 입력으로 움직인다. 자동 순환이라고 쓰지 않았다.
2. 원근법의 한 소실점으로 수렴하는 것은 해당 방향으로 평행한 선이다. 화면 속 모든 선이 모인다고 쓰지 않았다. 책가도는 일점 선원근법과 다른 공간 표현이며 ‘잘못된 그림’이 아니다.
3. 카유보트와 반 고흐의 비교 이미지는 후대의 공간 구성 사례다. 르네상스 시대의 대표작으로 분류하지 않았다. 반 고흐의 공간을 정밀한 일점 원근법의 정답이라고 제시하지 않았다.
4. 초현실주의의 기본 연혁은 1924년 선언 중심으로 설명한다. 사이트의 1924–1966 표기를 이 사조의 확정된 소멸 연도로 확대하지 않는다. [MoMA](https://www.moma.org/collection/terms/surrealism)
5. 《빛의 제국》은 여러 판본이 있고 구겐하임 소장본은 1953–54, MoMA의 II는 1950이다. 현재 morning.png의 정확한 원작 판본·디지털 가공 여부는 파일만으로 확정할 수 없다. 사이트는 1956이라고 표기하지만 이번 패널 캡션은 ‘연작을 모티프로 한 사이트 화면’으로 제한했다. [Peggy Guggenheim Collection](https://www.guggenheim-venice.it/en/art/works/empire-of-light/), [MoMA 소장본](https://www.moma.org/collection/works/78456)
6. 《안개 바다 위의 방랑자》는 사이트에 1818이 있으나 현재 소장처는 약 1817로 기재한다. 대본과 패널 별도 캡션에서는 연도를 생략해 모순된 확정을 피했다. 캡처 자체의 문자는 바꾸지 않았다. [Hamburger Kunsthalle](https://www.hamburger-kunsthalle.de/en/news/wanderer-above-sea-fog-caspar-david-friedrich)
7. 우아한 시체는 여러 사람이 앞선 그림을 가리고 이어 그리는 공동 놀이이며, 사이트는 미리 마련된 이미지 조각의 디지털 재조합이다. ‘재해석’이라는 차이를 밝혀 두었다. [MoMA](https://www.moma.org/collection/terms/exquisite-corpse)
8. 낭만주의의 숭고는 단순한 두 감정의 합이나 행복한 풍경의 동의어가 아니다. 압도적인 자연과 이를 마주하는 주체의 경험에 초점을 맞췄다. 낭만주의 전반을 한 작품으로 완전히 정의하지 않는다. [The Met](https://www.metmuseum.org/essays/romanticism)
9. 갤러리의 ‘비너스의 탄생=신 대신 인간을 그린 르네상스의 시작’, ‘아담의 창조=1508–1512’ 같은 문구는 이번 원고에서 재사용하지 않았다. 후자는 개별 장면과 천장화 전체의 제작 기간이 섞일 수 있으므로 별도 확인이 필요하다.
10. 음악 켜기/끄기는 있지만 기존 문서가 언급한 ‘나레이션용 설정’은 현재 소스에서 확인하지 못했다. 편집 과정에서 오디오를 조정하도록 안내했다.

## 검증 범위

screen-captures의 PNG는 현재 로컬 서버의 화면을 별도 렌더링한 자료다. 소실점 정렬, 날씨 변화, 꿈의 방 전환, 레버 조합, 갤러리 경유 여부는 캡처 기록과 함께 확인한다. 구체적인 결과는 screen-captures/capture-log.json에 기록한다. 카메라 HAND 기능, 모든 기기에서의 동작, 최종 녹음 시간, 실제 인쇄 출력은 검증 범위가 아니다.
